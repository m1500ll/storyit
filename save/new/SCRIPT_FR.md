# « Le pont sur lequel tout le monde s'est penché » — script FR v1 (2026-11-05)

## Script
Douze mille personnes ont un jour voulu regarder une course d'aviron depuis le même pont. Le pont, lui, n'était pas ravi.
Londres, mille huit cent soixante-dix. Le pont de Hammersmith est le premier pont suspendu sur la Tamise, et la meilleure place gratuite pour la course d'aviron entre Oxford et Cambridge.
Alors tout le monde arrive en avance. D'abord, les trottoirs se remplissent. Puis la chaussée. Puis le moindre petit trou.
Et quand les deux bateaux apparaissent enfin, douze mille personnes se ruent du même côté pour voir.
Les chaînes grincent. Tout le tablier se met à tanguer.
Heureusement, le pont a tenu.
Malheureusement, les propriétaires regardaient aussi.
Vous voyez, un pont est fait pour porter un poids bien réparti. Restez au milieu, et les deux chaînes se partagent la charge. Serrez-vous tous d'un côté, et ce côté s'enfonce pendant que l'autre se soulève.
Vous êtes déjà monté dans une barque où tout le monde se penche du même côté ? Même barque, mêmes gens, mais là, elle bascule.
Douze mille personnes sur un seul bord, c'était exactement ça, pour un pont.
Alors le vieux pont à chaînes a été démoli, et un pont plus solide a ouvert sur les mêmes piles en mille huit cent quatre-vingt-sept.
Il est toujours debout aujourd'hui. Mais depuis deux mille dix-neuf, il est interdit aux voitures. Des fissures.
